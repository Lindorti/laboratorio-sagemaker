# Evidencias de los laboratorios Amazon SageMaker

Esta carpeta contiene las capturas de pantalla y evidencias del desarrollo de los laboratorios 3.4 y 3.5 de Amazon SageMaker.

## Laboratorio 3.4: Formación de un modelo
Se documentan la preparación de los datos, su carga en Amazon S3 y el entrenamiento del modelo XGBoost.

## Laboratorio 3.5: Implementación de un modelo
Se documentan el despliegue del modelo, la validación del endpoint `xgb_predictor` y la interpretación de los resultados.
